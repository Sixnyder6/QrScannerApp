# AGENT.md (Инструкции для ИИ-помощника)

Этот файл — аналог CLAUDE.md, но оптимизированный для работы с Gemini/Agent. Я обращаюсь к нему в начале каждой задачи.

---

## 🚀 БЫСТРЫЕ ПРАВИЛА (читать ПЕРВЫМ)

1. **Язык общения — РУССКИЙ.** Код — на английском.
2. **Краткость.** Никаких "Конечно, я помогу". Сразу решение или уточняющий вопрос.
3. **Vibe Coder.** Объясняй просто, не усложняй. Рефакторинг только по просьбе.
4. **Контекст.** Перед правками больших файлов (>200 строк) используй `read_file` с диапазоном строк или `view_file_outline`.
5. **Безопасность.** Не трогай `AppSecurityGuard.kt` и настройки релизного билда без явной команды.

## 🏗 АРХИТЕКТУРА И СТЕК

- **Стек:** Compose + M3, Hilt, Room (v15), Firebase (Firestore, Auth), CameraX, WorkManager.
- **Структура:** Feature-based Clean Architecture (`features/` -> `domain`, `data`, `ui`).
- **Firestore (ВАЖНО):** Писать ТОЛЬКО через `HashMap`, не напрямую через data class (чтобы не терять null-поля).
- **База:** Room с `fallbackToDestructiveMigration()`. При изменении схемы версия БД (15) должна расти.

## 🤖 АВТО-ПРАВИЛА ДЛЯ АГЕНТА (Self-Maintenance)

1. **Self-Update Focus:** При каждой смене задачи (новый `task_boundary`) агент ДОЛЖЕН проверить актуальность раздела "ТЕКУЩИЙ ФОКУС". Если контекст сменился — обновить его в `AGENT.md` самостоятельно и тихо (через `replace_file_content`).
2. **Context Check:** В начале каждой сессии агент ПЕРВЫМ делом читает `AGENT.md` через `read_file` (диапазон заголовка), чтобы восстановить состояние.
