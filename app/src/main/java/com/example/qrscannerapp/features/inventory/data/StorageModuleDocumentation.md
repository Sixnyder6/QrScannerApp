# Документация по модулю Storage (Склад/Хранение)

Этот документ описывает структуру и назначение файлов, относящихся к функционалу управления хранением (ячейками склада) внутри модуля `inventory`.

---

### 📂 `features/inventory/data/repository`

#### 📄 `StorageRepository.kt`
**Назначение:** Основной репозиторий для управления ячейками хранения (Storage Cells) в Firebase Firestore.
- **Функционал:** 
  - Получение списка всех ячеек в реальном времени через `Flow`.
  - Добавление, удаление и редактирование ячеек.
  - Управление содержимым ячеек (добавление/удаление ID объектов, например, самокатов).
  - Перемещение объектов между ячейками.
  - Очистка ячеек.
- **Технологии:** Firebase Firestore (коллекция `storage_cells`).

---

### 📂 `features/inventory/data/export`

#### 📄 `StorageExportManager.kt`
**Назначение:** Логика экспорта данных о ячейках в формат Excel (.xlsx).
- **Режимы экспорта:**
  - `exportCellAsIs`: Экспорт одной ячейки в одну колонку (новые записи сверху) для быстрого просмотра.
  - `exportCellForPrinting`: Подготовка ячейки к печати (разбивка на колонки по 50 записей, сортировка, отступы для разрезания бумаги).
  - `exportAllCellsToExcel`: Полный бэкап всего склада, где каждая ячейка представлена в отдельном столбце.
- **Технологии:** Apache POI.

#### 📄 `PalletExportManager.kt`
**Назначение:** Специализированный экспорт данных, сфокусированный на паллетах (укрупненных единицах хранения). Позволяет выгружать содержимое паллет для логистики.

#### 📄 `PalletLabelGenerator.kt`
**Назначение:** Генерация этикеток/маркировок для паллет. Вероятно, создает PDF или изображения с QR-кодами и текстовой информацией для физической наклейки на паллеты.

---

### 📂 `features/inventory/data/mapper`

#### 📄 `InventoryMappers.kt`
**Назначение:** Преобразование (маппинг) данных между различными слоями приложения.
- **Функционал:** Конвертирует модели данных из Firebase Firestore (DTO) в доменные модели или сущности локальной базы данных и обратно. Обеспечивает чистоту данных и независимость UI от структуры БД.

---

### 📂 `features/inventory/data/worker`

#### 📄 `InventorySyncWorker.kt`
**Назначение:** Фоновый воркер (WorkManager) для синхронизации данных инвентаризации.
- **Функционал:** Гарантирует, что изменения, сделанные в оффлайн-режиме, будут отправлены в Firebase при появлении интернета. Отвечает за целостность данных между локальным кэшем и облаком.
- **Технологии:** Jetpack WorkManager.
