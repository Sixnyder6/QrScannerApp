# Модуль Сканера (Scanner Feature)

Данный модуль отвечает за функциональность сканирования QR-кодов, управление сессиями сканирования и обработку данных.

## Структура пакета

### `ui/` - Слой представления
Включает в себя компоненты интерфейса для работы со сканером.
- **`components/`**:
    - `CameraView.kt`: Интерфейс камеры и логика захвата изображений/кодов.
    - `ExportSheet.kt`: Панель экспорта данных сессии.
    - `SessionStats.kt`: Компоненты для отображения статистики сканирования.
    - `ScanListItems.kt`: Отрисовка элементов в списке отсканированных объектов.
    - `ScannerDialogs.kt`: Вспомогательные диалоги (удаление, ошибки, подтверждения).
    - `BatchSetupSheet.kt`: Настройка параметров для серийного (пакетного) сканирования.
    - `NumberModeComponents.kt`: UI-элементы для режима ручного ввода инвентарных номеров.
    - `ScooterSearchResultDialog.kt`: Отображение информации о найденном самокате.

### `domain/` - Бизнес-логика и модели
Чистая логика приложения, не зависящая от фреймворков.
- **`model/`**:
    - `ScanModels.kt`: Определения `ScanItem`, `ScanSession` и связанных перечислений.
- **`util/`**:
    - `ScannerCodeUtils.kt`: Логика обработки строк (извлечение ID из URL, валидация кодов).

### `data/` - Слой данных
Реализация хранения и получения данных.
- **`local/`** (Локальное хранилище Room):
    - **`dao/`**: `ScanSessionDao.kt` — SQL-запросы к БД.
    - **`entity/`**: `ScanSessionEntity.kt` — Схема таблицы в базе данных.
    - **`converter/`**: `ScanConverters.kt` — Преобразование сложных типов для Room.
- **`repository/`**:
    - `ScanSessionRepository.kt`: Единая точка доступа к данным сканирования (связка локальной БД и API).
