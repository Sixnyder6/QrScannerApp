# 💬 Chat Module

## Обзор
Модуль **Chat** обеспечивает внутреннюю коммуникацию между сотрудниками (муверами, менеджерами склада, СБ) внутри приложения. Поддерживает тематические комнаты, личные сообщения и систему реакций.

---

## 📁 Структура модуля

```
features/chat/
├── domain/model/
│   └── ChatMessage.kt      ← Основная модель сообщения и список комнат
├── ui/
│   ├── ChatScreen.kt       ← Список комнат и общий интерфейс
│   ├── ChatViewModel.kt    ← Логика групповых чатов
│   ├── DirectChatScreen.kt ← Экран личных сообщений
│   └── DirectChatViewModel.kt
└── data/                   ← (Опционально) Репозитории и источники данных
```

---

## 🏛️ Комнаты (ChatRoom)
Система разделена на тематические каналы:
- **💬 Общий (general)**: Флуд и общие вопросы.
- **🛴 Мувéры (muvers)**: Рабочие вопросы логистики и перемещения самокатов.
- **📦 Склад (managers)**: Взаимодействие со складом и запчастями.
- **⏱ Смена (shifts)**: Координация текущей рабочей смены.
- **🔔 Оповещения (alerts)**: Системные уведомления и критические алерты.

---

## ✨ Функциональные возможности

### Типы сообщений (`MessageType`)
- `TEXT`: Обычное текстовое сообщение.
- `IMAGE`: Передача фотографий (например, состояние самоката).
- `SYSTEM`: Системные уведомления о действиях пользователей.
- `ALERT`: Важные оповещения с особым выделением.
- `EMOJI_REACTION`: Реакции на сообщения.

### Механики
- **Реакции**: Возможность ставить эмодзи на сообщения.
- **Ответы (Replies)**: Поддержка цепочек ответов (`replyToId`).
- **Упоминания (Mentions)**: Уведомления пользователей через `@name`.
- **Статус прочтения**: Отслеживание списка пользователей, прочитавших сообщение (`readBy`).
- **Временные сообщения**: Поддержка срока жизни сообщения (`expiresAt`).

---

## 🛠 Технический стек
- **Firebase Firestore**: Хранение сообщений в реальном времени.
- **ServerTimestamp**: Синхронизация времени сообщений на стороне сервера.
- **Jetpack Compose**: Современный UI с поддержкой анимаций и состояний.

---

## 🔗 Интеграция с UI
Для уведомлений вне чата используется компонент `ChatNotificationBanner.kt` (в `common/ui`), который показывает всплывающие сообщения поверх других экранов приложения.
