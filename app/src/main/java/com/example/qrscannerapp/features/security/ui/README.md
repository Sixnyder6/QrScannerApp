# 🛡️ Security Module — UI Layer

## Обзор
Модуль **Security** предназначен для сотрудников службы безопасности и логистики. Он обеспечивает мониторинг флота, управление проблемными самокатами (угоны, поджоги, утопленники), импорт данных и аналитику по хабам.

---

## 📁 Структура файлов

```
features/security/ui/
├── SecurityDashboardScreen.kt    ← Главный дашборд безопасности
├── SecurityViewModel.kt          ← Общая бизнес-логика модуля
├── Securityscootersscreen.kt     ← Список и управление самокатами
├── Securitybatteryscreen.kt      ← Мониторинг АКБ
├── Securitystoragescreen.kt      ← Управление хранением
│
├── fleet/                        ← Управление парком (импорт/обновление)
│   ├── FleetImportScreen.kt
│   ├── FleetImportSheet.kt
│   └── FleetImportViewModel.kt
│
└── scanner/                      ← Специализированный сканер безопасности
    ├── SecurityScannerScreen.kt
    └── SecurityScannerViewModel.kt
```

---

## 📊 Основные экраны

### `SecurityDashboardScreen.kt`
Центральный узел модуля. Предоставляет быструю сводку:
- **Quick Stats**: Оперативные счетчики по категориям (Самокаты, АКБ, Склад).
- **Tag Breakdown**: График распределения проблемных самокатов по типам (Угоны, Вскрытия и т.д.).
- **Hub Breakdown**: Статистика активности по конкретным локациям (Бестужевская, Софийская).
- **Recent Activity**: Лента последних событий безопасности.

### `Securityscootersscreen.kt`
Экран для работы с проблемным флотом.
- Фильтрация по тегам безопасности.
- Отображение статусов: "Угон", "Поджог", "Вскрытый", "Без АКБ", "Утопленник".
- Быстрый переход к деталям конкретной единицы.

### `FleetImport (папка fleet/)`
Инструментарий для массового обновления данных о парке.
- Поддержка импорта из внешних источников.
- Отображение прогресса и результатов импорта.

---

## ⚙️ Бизнес-логика

### `SecurityViewModel.kt`
Управляет состоянием всего модуля:
- Подписка на обновления Firestore для real-time статистики.
- Группировка данных по хабам (`SecurityHubs`) и тегам (`ScooterTag`).
- Логирование действий сотрудников через `TelemetryManager`.

### `SecurityScannerViewModel.kt`
Специализированная логика для сканера безопасности, отличающаяся от обычного складского сканера:
- Проверка статуса безопасности при сканировании.
- Мгновенное оповещение о критических тегах (например, "В розыске").

---

## 🎨 Дизайн и темы
Модуль использует специфичную палитру `SecColors` (определена в Dashboard), ориентированную на быстрое считывание критической информации:
- 🔴 **Красный**: Критические проблемы (Угоны, Пожары).
- 🟠 **Оранжевый**: Требует внимания (Вскрытия).
- 🔵 **Синий**: Логистические статусы.

---

## 🔗 Интеграции
- **Firestore**: Основной источник данных для дашборда и списков.
- **AuthManager**: Разграничение прав доступа (только для роли Security).
- **TelemetryManager**: Сбор статистики действий для аудита.
