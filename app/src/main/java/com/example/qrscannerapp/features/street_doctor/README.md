# 🩺 Модуль Street Doctor (Полевой ремонт)

Модуль предназначен для автоматизации работы выездных техников («уличных врачей»), занимающихся оперативным обслуживанием, диагностикой и мелким ремонтом самокатов непосредственно на точках их дислокации.

## 🚀 Основные функции

*   **Управление задачами:** Персональные списки заданий с расчетом дистанции до самокатов в реальном времени.
*   **QR-Идентификация:** Быстрый поиск юнита и переход в его паспорт через встроенный сканер.
*   **Технический паспорт:** Полная информация о состоянии (заряд, пробег, VIN) и фиксация выполненных работ.
*   **Администрирование:** Массовый импорт задач из XLSX с распределением по техникам и контролем активных сессий.
*   **Складская логика:** Формирование списков на эвакуацию (`StorageList`) и интеграция с общим складом.

## 📂 Структура модуля (по файлам)

### 🏗 Data & Domain
*   **`data/StreetDoctorRepository`** — центральный репозиторий для взаимодействия с Firebase Firestore.
*   **`domain.model/StreetScooter.kt`** — основная модель данных самоката и статусы поля.
*   **`domain.model/RepairJob`** — модель данных для учета проведенных работ.

### 📱 UI: Основные экраны и логика
*   **`ui/StreetDoctorHost.kt`** — навигационный хаб и точка входа в модуль.
*   **`ui/FieldHubScreen.kt`** — центральная панель (дашборд) модуля.
*   **`ui/TasksScreen.kt`** — основной список задач техника с фильтрацией.
*   **`ui/TechnicScannerScreen.kt`** — экран высокопроизводительного QR-сканера.
*   **`ui/PassportScreen.kt`** — детальная карточка самоката и форма отчета.
*   **`ui/StorageListScreen.kt`** — интерфейс управления юнитами для отправки на склад.
*   **`ui/StreetDoctorViewModel.kt`** — базовая бизнес-логика функционала техника.

### ⚙️ UI: Администрирование и Импорт
*   **`ui/FieldRepairAdminScreen.kt`** — панель мониторинга выездов для администраторов.
*   **`ui/FieldRepairAdminViewModel.kt`** — управление сессиями и контроль техников.
*   **`ui/FieldRepairImportSheet.kt`** — шторка для импорта заданий из Excel (XLSX).
*   **`ui/FieldRepairImportViewModel.kt`** — логика парсинга, валидации и распределения задач.
*   **`ui/ImportPreferencesManager.kt`** — хранение локальных настроек и пресетов импорта.

### 🧩 UI: Вспомогательные компоненты
*   **`ui/ScooterInfoSheet.kt`** — быстрая информационная панель о самокате.
*   **`ui/StreetDoctorBottomNav.kt`** — специализированная нижняя навигация.
*   **`ui/StreetDoctorMenuSheet.kt`** — контекстное меню профиля и настроек модуля.

## 🛠 Технологический стек
*   **UI:** Jetpack Compose (Material 3).
*   **Backend:** Firebase Firestore (Real-time sync).
*   **Excel:** Обработка XLSX для формирования планов работ.
*   **Location:** Расчет дистанций через Android Telemetry/Location API.
*   **DI:** Hilt.
