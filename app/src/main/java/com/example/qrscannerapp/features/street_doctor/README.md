# Модуль Street Doctor (Полевой ремонт)

Модуль предназначен для работы выездных техников («уличных врачей»), занимающихся обслуживанием и мелким ремонтом самокатов непосредственно на точках их расположения.

## Основные функции

*   **Список задач:** Отображение назначенных техникам самокатов, требующих внимания.
*   **Управление статусами:** Возможность взять самокат в работу, отметить ремонт как выполненный, пометить самокат как «не найденный» или отправить его на склад.
*   **Навигация и Геолокация:** Расчет расстояния до каждого самоката в реальном времени на основе текущего местоположения техника.
*   **Паспорт самоката:** Просмотр детальной информации о техническом состоянии конкретной единицы.
*   **Администрирование:** Интерфейс для импорта новых задач и управления активными сессиями ремонта.
*   **Синхронизация:** Реализована через Firebase Firestore, что обеспечивает мгновенное обновление данных у всех участников процесса.

## Структура модуля

*   `domain/model/`: Описание моделей данных (`StreetScooter`, `RepairJob`) и статусов.
*   `data/`: Репозитории для работы с источниками данных (Firestore).
*   `ui/`: Компоненты пользовательского интерфейса на Jetpack Compose:
    *   `TasksScreen.kt` — основной экран со списком задач.
    *   `StreetDoctorViewModel.kt` — бизнес-логика и управление состоянием экрана.
    *   `FieldHubScreen.kt` — центральный хаб модуля.
    *   `FieldRepairAdminScreen.kt` — панель администратора для импорта заданий.

## Технологический стек

*   **UI:** Jetpack Compose (Material 3)
*   **DI:** Hilt
*   **Backend:** Firebase Firestore (Real-time updates)
*   **Архитектура:** MVVM
*   **Location:** Расчет расстояний через Android Telemetry/Location API

## Как использовать

1.  Модуль активируется через `StreetDoctorHost.kt`.
2.  При входе техник видит список самокатов, отсортированных по удаленности.
3.  Для начала работы необходимо нажать «Взять в работу» в карточке самоката.
4.  После завершения манипуляций статус меняется на «Готово» или «На склад».
